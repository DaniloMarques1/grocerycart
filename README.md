# Grocery Cart

It's an app that you can use to create a grocery list with a budget and follow while shopping.

With the app, you will be able to:

1. Create a new grocery list
2. Add categories that make sense to you
3. add items to those categories
4. Mark each item as bought and add a price to it so that you can know if you are reaching your budget

In the end, you will be able to create a report with the list and share it.
